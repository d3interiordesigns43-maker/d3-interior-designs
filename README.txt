HOW TO PUBLISH FOR FREE
1. Create a free GitHub account.
2. Create a new PUBLIC repository named: d3-interior-designs
3. Upload these 3 files to the repository root.
4. In Settings → Pages, choose Deploy from branch → main → /(root).
5. GitHub will give you a free *.github.io address.

USE YOUR GODADDY DOMAIN
In GitHub Pages, add your custom domain (for example www.yourdomain.com).
Then in GoDaddy DNS, add the CNAME record GitHub provides. Do not delete other required DNS records.
GitHub Pages hosting is free; your GoDaddy domain remains your domain.
